# responsive_app

# 📱 Responsive Flutter Chat & Dashboard

A clean dark-themed Flutter application featuring an interactive Chat Interface and Analytics Dashboard, fully responsive across Mobile and Tablet devices.

## ✨ Features
- 📐 **Responsive Design:** Seamlessly adapts to Mobile & Tablet screen sizes.
- 💬 **Interactive Chat:** Dynamic messaging with smooth auto-scroll to latest messages.
- 🎨 **Dark UI:** Custom color gradients and pixel-perfect design.
